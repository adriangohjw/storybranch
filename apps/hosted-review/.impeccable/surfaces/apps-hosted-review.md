# Run review

Mode: operate.

Audience: a teammate opening a run from a link to accept, request changes, or comment. Scope: hosted-review routes and the shared review-ui they render.

## Direction contract

THESIS: The window is the official color chip for this snapshot. Accept replaces the chip. The page refuses a grey app with a blue button.

OWN-WORLD: Paper #F3EEE4, ink #1A1714, pending #F5C518, accepted #1F7A4D, changes requested #E23B2F. Archivo, self-hosted. Sharp 2px corners. One notch punched in the specimen card. Standard buttons, selects, and links.

STORY: The visitor sees which decision the selected shot is in, compares baseline and actual, and accepts or requests changes. The shell color is that state.

FIRST VIEWPORT: The top bar and page ground are the state color. A paper sheet holds an equal-height shot list and the screenshot on a notched card. Story count sits on that card, next to the frame. Accept is a normal ink button on the card.

FORM: Municipal color-standard fan, seventh grounded candidate, seed def6f7ae.

SIGNATURE: When review state changes, the shell color eases to the new state, and the notch shows that color through the card.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
